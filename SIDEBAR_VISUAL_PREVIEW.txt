## ANIMATIONS
────────────────────────────────────────────────────────────────────────────────

1. MOBILE SIDEBAR SLIDE IN:
   ┌────┐                    ┌────────────┐
   │    │  →  →  →  →  →  →  │  Sidebar   │
   │    │                    │  visible   │
   └────┘                    └────────────┘
   Off-screen               On-screen
   (Spring animation)

2. SECTION COLLAPSE/EXPAND:
   ▼ Category        ▲ Category
   ─────────────     ─────────────
                     □ All Niches
   Height: 0         ✓ Technology
                     □ Business
                     ...
                     Height: auto
   (Smooth height animation)

3. PUBLISHER CARDS APPEAR:
   Card 1: Fade + slide up (delay: 0ms)
   Card 2: Fade + slide up (delay: 50ms)
   Card 3: Fade + slide up (delay: 100ms)
   ...
   (Staggered animation)

4. FILTER PILLS REMOVE:
   [Technology ✕]  →  [fade out]  →  (removed)
